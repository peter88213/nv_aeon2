# Contributing

## General

This repository is a part of the *novelibre* software project. 
Please be sure to follow the 
[central contribution guidelines](https://github.com/peter88213/novelibre?tab=contributing-ov-file). 


## Mandatory directory structure for building the plugin package

```
.
├── novelibre/
│   ├── i18n/
│   ├── src/
│   └── tools/ 
│       ├── msgfmt.py
│       ├── inliner.py
│       ├── package_builder.py
│       ├── pgettext.py
│       ├── translate_de.py
│       └── translations.py
└── nv_aeon2/
    ├── i18n/
    ├── src/
    │   └── nvaeon2/
    └── tools/ 
        └── build.py
```
